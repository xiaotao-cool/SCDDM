技术栈：Spring Boot + Spring Security + MyBatis + MySQL + Redis + RabbitMQ + Docker

项目简介

 设备资产管理系统用于单位办公设备的统一管理，实现设备信息维护、设备借用归还登记及权限管理，提升设备管理效率并减少人工登记错误。

项目规模

后端代码量约 6000+ 行
设计 11 张核心业务数据表
开发 20+ RESTful API接口
支持 设备信息管理、借用归还管理、权限管理等 5+ 核心功能模块

个人职责

独立完成系统 架构设计、数据库设计及后端开发。
基于 Spring Boot + MyBatis 构建系统后端架构，实现业务逻辑开发。
设计数据库结构并完成 11张数据表设计（设备表、借用记录表、用户表、角色表等）。
使用 Spring Security 实现系统登录认证及角色权限控制。
开发 设备信息管理模块，支持设备新增、修改、查询及状态管理。
实现 设备借用与归还流程管理，记录设备使用历史。
使用 Redis 实现热点数据缓存，减少数据库查询压力。
通过 MySQL索引优化查询语句，提升设备列表查询效率。
使用 Docker 进行项目容器化部署，实现项目快速部署与运行环境隔离。
完成系统接口测试与功能调试，保证系统核心功能稳定运行。
